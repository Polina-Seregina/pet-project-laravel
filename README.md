## О Проекте
Учебный проект для изучения возможностей фреймворка Laravel, и приобретения практических навыков разработки. 
Проект был разработан в Docker. Изначально проект написан на PHP 8.2 и Laravel 10. Впоследствии версии PHP и Laravel были подняты до PHP 8.5 и Laravel 13. 

### Цель проекта

Разработать платформу для продажи цифровых артов (NFT-подобных изображений). Пользователи могут загружать собственные изображения, продавать их, покупать арты других пользователей. 

### Документация
Подробная документация находится в директории docs. 

### Запуск проекта
1. 'make setup' - первичный запуск проекта (сборка Docker образов, запуск контейнеров, выполнение миграций, сидера и т.д.).
2. 'make up' - запуск проекта, поднятие Docker.
3. 'make stop' - остановка Docker-контейнеров
4. 'make down' - удаление контейнеров и томов

### Запуск тестов 
Тесты запускаются при поднятом Докере. 
- docker compose exec php php artisan test
