## **Перевод валюты**
*Механизм перевода валюты.*
*Отображение баланса кошелька и стоимости арта в выбранной валюте.*
*Доступные валюты в App\Enums\CurrencyEnum.*
*Перевод осуществялется с помощью сервиса App\Services\ExchangeRate, который использует стороннее Api для получения котировок.*

### Роуты управления 

### 1. POST /products/{product}
#### - name('products.currency')

*Отображение стоимости арта в выбранной валюте.*  
*Роут защищен мидлварой 'onlyPublic'. Перевод стоимости арта доступен только при условии, что чужой арт в статусе ProductsStatus::FORSALE. Либо для арта в любом статусе, если он принадлежит пользователю.*

*Входные данные*: ExchangeCurrencyRequest, Product $product  
*Формат ответа*: (302 OK) Redirect

### 2. POST /wallet
#### - name('wallet.currency')
*Отображение баланса кошелька в выбранной валюте.*

*Входные данные*: ExchangeCurrencyRequest  
*Формат ответа*: (302 OK) Redirect
