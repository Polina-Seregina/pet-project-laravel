### **Административная панель**

### Роуты управления 

#### 1. GET /admin/users

*Возвращает список всех пользователей.*

*Входные данные*: Request
*Формат ответа*: (200 OK) - text/html

#### 2. GET /admin/{user}

*Возвращает страницу пользователя с формой для изменения роли.*

*Входные данные*: Request, $user
*Формат ответа*: (200 OK) - text/html

#### 3. PATCH /admin/{user}

*Обновляет роль пользователя. В выпадающем списке две опции - admin и user.*
*Невозможно изменить роль только у пользователя 'admin', созданного в сидере RoleSeeder.*

*Входные данные*: Request, $user

*Формат ответа*: (302 OK)
