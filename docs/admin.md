### **Административная панель**
*Ордер/Заказ - сущность, хранящая информацию о купле-продаже Арта.*
*Содержит информацию о покупателе, продавце, дате, товаре, статусе заказа(CREATED, COMPLETED).*
*Сущность создается в транзакции (status - CREATED) при попытке купить товар. В случае успешно выполненной транзакции - заполняется поле new_product_id, статус меняется на COMPLETED.*
*Благодаря сущности Ордер, Пользователь имеет доступ к просмотру истории покупок и продаж.*

### Роуты управления 

#### 1. GET /admin/panel
*Возвращает базовую административную страницу.*

*Входные данные*: Request
*Формат ответа*: (200 OK) - text/html

#### 2. GET /admin/userslist

*Возвращает список пользователей с ролью 'user'.*

*Входные данные*: Request
*Формат ответа*: (200 OK) - text/html

#### 3. GET /admin/list

*Возвращает список пользователей с ролью 'admin'.*

*Входные данные*: Request
*Формат ответа*: (200 OK) - text/html

#### 4. GET /admin/{user}

*Возвращает страницу пользователя с формой для изменения роли.*

*Входные данные*: Request, $user
*Формат ответа*: (200 OK) - text/html

#### 5. PATCH /admin/{user}

*Обновляет роль пользователя. В выпадающем списке две опции - admin и user.*
*Невозможно изменить роль только у пользователя 'admin', созданного в сидере RoleSeeder.*

*Входные данные*: Request, $user

*Формат ответа*: (302 OK)
