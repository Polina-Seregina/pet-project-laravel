## **Административная панель**
*Админ -  пользователь с ролью 'admin'.*  
*Главный админ создается в сидере RoleSeeder при запуске проекта.*  
*Админ может менять роль пользователей, зарегистрированных на бирже. В дальнейшем функционал административной панели может быть расширен.*

### Роуты управления 

### 1. GET /admin/users
#### - name('admin.index')

*Возвращает список всех пользователей.*
*Можно перейти к роуту 'admin.show', нажав на стрелку в первом столбце.*

*Входные данные*: Request  
*Формат ответа*: (200 OK) - text/html

### 2. GET /admin/{user} 
#### - name('admin.show')

*Возвращает страницу пользователя с формой для изменения роли.*

*Входные данные*: Request, $user  
*Формат ответа*: (200 OK) - text/html

### 3. PATCH /admin/{user}
#### name('admin.update')

*Обновляет роль пользователя. В выпадающем списке две опции - admin и user.*
*Невозможно изменить роль только у пользователя 'admin', созданного в сидере RoleSeeder.*

*Входные данные*: UserUpdateRequest, $user

*Формат ответа*: (302 OK)
